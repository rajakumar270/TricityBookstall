# 📁 Data Directory for Excel Import

Place your Excel sheets in this folder:

1. `ap_foundation_books.xlsx` (or `.csv`) - Books by Acharya Prashant Foundation
2. `other_author_books.xlsx` (or `.csv`) - Books by Other Authors

Expected Excel Columns (Any format will be parsed flexibly):
- **Title** / Book Name
- **Author**
- **Category** / Main Category (Acharya Prashant Foundation or Other Author)
- **MRP** (Maximum Retail Price in ₹)
- **Buying Cost** / Cost Price (in ₹)
- **Selling Price** (in ₹)
- **Stock** / Quantity
- **Language** (English / Hindi / Bilingual)
- **Is Kids Book?** (Yes/No or True/False)
- **Image URL** / Image Link
